## Delivered Outcomes

- Workspace navigation, cache isolation, async mutation scoping, offline draft
  recovery, database management, knowledge recovery, reminders, collaboration,
  account center, and mobile layout were hardened across the release series.
- The editor remains the dominant note surface and the inspector is on demand.
- 390 px and 200% zoom no longer allow account navigation to cover the note
  body.
- AI receives explicit scoped read context and supports confirmed product
  actions including notes, reminders, notifications, database operations, and
  system-address email.
- System AI uses OrcaRouter Qwen3.8 27B Free with one transient retry and
  Workers AI failover. Personal AI remains encrypted per user and can fall back
  through system AI to Workers AI.
- Personal AI configuration includes OrcaRouter plus one-click DeepSeek V4
  Flash Free and Qwen3.8 27B Free model IDs.
- Cloudflare-to-OrcaRouter requests use manual redirect handling and reject all
  non-2xx responses, preserving the no-follow Authorization boundary.
